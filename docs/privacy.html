temp emails and opsec

temp emails are just good in general but i dont want people doxxing themselves just cause its the best way to get a reply from me.

why use them

discord support, random server verifications and modded client feedback forms always ask for an email. if u hand over ur personal gmail ur basically tying ur real identity to whatever ur doing. temp inboxes let u get the verification code or support reply without leaving a paper trail.

dont use temp domains for ur main acc. discord flags a lot of these domains and u might get locked out or banned. if u need a permanent burner for ur main, use something like protonmail, atomic mail, or simplelogin.

recommended providers

  • mail.tm - super fast, reliable and has a clean api if ur making scripts or selfbots that need to auto verify
  • atomic mail - decent UI, discord support, and also permanent inbox. not a big company, but still privacy focused
  • proton mail - not temp but if u need a permanent inbox that doesnt log ur ip or sell ur data, use this. pair it with simplelogin for aliases
  • guerrilla mail - the classic. UI is scuffed but it works when everything else is down
  • 10minutemail - good for literally just grabbing one code and forgetting about it

general tips

  • never use an email tied to ur real name or main socials for discord alt accounts
  • if a service requires phone verification too, look into sms pooling sites or just use a different alt
  • clear ur cookies and use a different fingerprint if ur making alts on the same machine
