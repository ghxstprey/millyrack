Getting Started

get doiksub installed and injected into Discord in a few steps.

Requirements

  • Node.js — v18 or later recommended
  • pnpm — used for package management
  • Discord desktop (Stable, PTB, or Canary)
💡

Windows users: if you'd rather skip the manual setup, see the Windows batch file method below.

Windows — RunOnWindows.bat

the repo ships a batch file that handles everything automatically. just double-click it:

RunOnWindows.bat

it installs dependencies, builds doiksub, and runs the installer. that's it.

Manual Install

  1. 1
    Clone the repo
    git clone https://github.com/ghxstprey/doiksub.git
cd doiksub
  2. 2
    Install dependencies
    pnpm install --frozen-lockfile
  3. 3
    Build & inject
    pnpm build && node scripts/runInstaller.mjs -- --install

    add -auto to skip the manual injection prompt:

    pnpm build && node scripts/runInstaller.mjs -- --install -auto
  4. 4
    Restart Discord

    fully quit and relaunch Discord. doiksub should be active.

Build & Inject (quick ref)

# install deps
pnpm install --frozen-lockfile

# build + inject
pnpm build && node scripts/runInstaller.mjs -- --install

# rebuild only (no reinstall needed if already injected)
pnpm build

Scaffolding a New Plugin

use the built-in generator to scaffold a new plugin:

pnpm new-plugin myPluginName

this creates a new folder under src/plugins/myPluginName/ with a starter index.ts.

see the Contributing page for plugin rules before you start.

Repo Structure

path what's in it
src/plugins/ all plugins and feature packs
src/utils/constants.ts doiksubDevs — developer identity list
scripts/ build tools, installer, plugin generator
browser/ browser extension build output
dist/ compiled output (generated)
packages/ internal workspace packages
